# 01 · 大数据概论

## 大数据的 4V 特征

| 特征 | 英文 | 含义 |
|:---|:---|:---|
| 大量 | Volume | 数据体量从 TB 到 PB 级 |
| 高速 | Velocity | 数据产生和处理的速度要求高 |
| 多样 | Variety | 结构化、半结构化、非结构化数据并存 |
| 价值 | Value | 数据总量大但价值密度低，需要挖掘 |

> 补充：也有 **5V** 的说法，多一个 **Veracity（真实性）**，强调数据质量问题。

## Hadoop 发展史

1. **2003**：Google 发表 GFS 论文
2. **2004**：Google 发表 MapReduce 论文
3. **2006**：Google 发表 BigTable 论文；Doug Cutting 基于前三篇论文实现 Hadoop
4. **2008**：Hadoop 成为 Apache 顶级项目
5. **现在**：Hadoop 3.x 支持 NameNode HA、纠删码、YARN 资源调度等

## Hadoop 生态圈

| 组件 | 定位 |
|:---|:---|
| **HDFS** | 分布式文件系统，解决海量数据存储 |
| **MapReduce** | 分布式计算框架，解决海量数据计算 |
| **YARN** | 资源调度框架，管理集群 CPU / 内存 |
| **ZooKeeper** | 分布式协调服务，用于选主、配置管理 |
| **Hive** | 基于 HDFS 的数据仓库，把 SQL 翻译成 MR/Spark 任务 |
| **HBase** | 基于 HDFS 的列式 NoSQL 数据库，支持随机读写 |
| **Flume** | 日志采集，把数据从文件采集到 HDFS/Kafka |
| **Sqoop / DataX** | 关系型数据库与 HDFS 之间的批量数据同步 |
| **Spark** | 基于内存的分布式计算框架，比 MR 快 |
| **Flink** | 真正的流处理框架，支持流批一体 |

## 大数据在「新基建」中的位置

新基建包含 5G 基站、特高压、城际高铁、新能源汽车充电桩、大数据中心、人工智能、工业互联网。**大数据中心是其他几项的数据底座**——5G 产生数据、数据中心存储和计算数据、AI 消费数据。
